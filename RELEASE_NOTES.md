LedgerDesk 1.1.0 packages the offline income and expense tracker as a portable
Windows x64 application. Python and Tcl/Tk are bundled.

Download the Windows ZIP, extract the complete folder, and open LedgerDesk.exe.
Keep the app and runtime folders beside the EXE. Existing ledgers remain in the
user's separate LedgerDesk data folder.

Includes transaction editing, separate currency totals, charts, filters, CSV
export, backups, daily snapshots, and restoration with a safety copy.

The source includes automated data checks, locked runtime hashes, an executable
build script, and a packaged-runtime self-test.

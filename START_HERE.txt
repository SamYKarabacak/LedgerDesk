LEDGERDESK 1.1.0 - SOURCE

To use the Windows app, download LedgerDesk-v1.1.0-Windows-x64.zip
from the repository's Releases page. Extract the whole ZIP and open
LedgerDesk.exe. Python is included.

This folder contains the source, build tools, tests, and GitHub workflows.
Start with README.md. GITHUB_SETUP.md covers builds and new releases.

To run the source, install Python 3.10+ with Tcl/Tk and use
Run_From_Source_Windows.bat or python income_tracker.py.
